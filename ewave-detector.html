📐 斐波那契关键位

📚 教学一：艾略特波浪是什么？（是什么）

一句话：市场价格按「5 浪推动 + 3 浪调整」的节奏循环前进，这就是趋势的「呼吸」。艾略特波浪理论（Elliott Wave）就是用这套节奏给行情“分浪”，判断我们现在处在这一口气里的哪一个阶段。

五浪推动（ trend 方向）：浪1 起步 → 浪2 回调（不破浪1起点）→ 浪3 往往最长最猛 → 浪4 回调（不与浪1重叠）→ 浪5 最后一冲。五浪走完，一段趋势就到头了。

三浪调整（ counter-trend）：A 下跌 → B 反弹（不超过A起点）→ C 再跌（常与A等长的 0.618~1.618 倍）。ABC 结束后，下一轮五浪推动重新开始。这就是「分形」——大浪里套小浪，日K的浪在周K里可能只是一个子浪。

三铁律（数浪对错的关键）：① 浪2 不能跌破浪1起点；② 浪3 不能是三个推动浪里最短的；③ 浪4 不能与浪1 重叠（普通浪，倾斜三角形除外）。违反任一条，这串摆动就不是有效五浪。

📚 教学二：为什么要用它？斐波那契又是什么？（为什么）

为什么数浪有用：它能把“现在该买还是该卖”从感觉变成位置判断——如果你知道刚走完五浪、正在ABC调整，那眼前的反弹就该谨慎、等C到位；如果你知道在浪3主升，回踩就是顺势低吸。同时它给出明确的失效位（如跌破浪2低点结构就破），止损清晰。

斐波那契（黄金分割）：自然界普遍存在的比例（0.618、1.618…）。股市里，回调和反弹常常停在一段行情的 0.382 / 0.5 / 0.618 / 0.786 位置；下一浪目标常落在 1.272 / 1.618 / 2.618 倍。它给数浪补上了“具体到哪个价”的量尺。

两者怎么配合：数浪定“方向/阶段”，斐波那契定“价格目标”。比如五浪完成后的回调，0.5~0.618 是经典低吸区；ABC 里 C 跌到 A 的 1.272~1.618 倍且止跌，反弹第一目标看整段跌幅的 0.382~0.5。两者共振，信号更可信。
